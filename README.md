Levantamento de Requisitos
1 – Nome da Squad:
FuturoTech
2 – Escopo do Sistema:
O sistema terá como objetivo receber dados de vendas, verificar se as informações estão
corretas e apresentar os resultados de forma simples para facilitar a análise, o usuário poderá enviar um
arquivo com dados de vendas. O Sistema irá verificar possíveis erros ou informações faltantes e, depois,
apresentar os dados organizados para consulta.
3 – Requisitos funcionais:
Enviar arquivo: O Sistema deve permitir que o usuário envie um arquivo CSV contendo os
dados das vendas.
Validar os dados: O Sistema deve verificar se os dados enviados estão completos e se existem
informações inválidas ou faltantes.
Exibir resultados: O Sistema deve apresentar os dados das vendas de forma organizada para
que o usuário possa consultar as informações.
4 – Requisitos Não funcionais:
Facilidade de uso: O Sistema deve possuir uma interface simples e fácil de utilizar.
Desempenho: O Sistema deve realizar validação dos dados em poucos segundos, evitando
demora para o usuário.

5 – Resumo do Sistema:
O projeto consiste em um Sistema simples para consumo e qualidade de dados de vendas. O objetivo é
facilitar o recebimento, validação e visualização das informações. O Sistema será pensado para reduzir
erros nos dados e facilitar o trabalho de quem precisa analisar essas informações.
